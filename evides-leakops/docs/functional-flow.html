From pressure alarm to water back on the tap

Six AI agents in Microsoft Foundry work together after a burst-main alarm: they judge the alarm, locate the damage, inform residents, find the right technician, secure the parts and plan the repair. People stay in control of every decision that matters.

Safe by design

The model judges and writes. Code owns the facts and the rules.

Rule checks in code

Every answer is re-checked: certification, approval limits, wording, safety margin. A broken rule means needs review, never silent approval.

Short-circuit on false alarms

Planned works or a low-confidence alarm closes the flow early. Fewer call-outs and no unnecessary resident notices.

Content filter on input

Prompt-injection attempts such as "ignore all previous instructions" are blocked by the Foundry content filter before the model sees them.

Human approval

Orders above €2,500 and any needs review result wait for an operator. People stay accountable.

What Microsoft Foundry adds

The agents are not hidden in code: they live in the Foundry portal.

Agents & versions

Six named agents (Triage to Scheduling) with instructions, model and tools in one place, versioned and reusable.

Tracing

Each run shows agent, model call and tool call as spans in Application Insights. Ideal for audits and root cause.

Evaluations

Test questions with expected answers plus task-adherence and tool-success judges: Triage 4/4, Diagnostic 1/1.
